  Nathalie Mota - Thème enfant WordPress

Projet réalisé dans le cadre de ma formation "Développeur WordPress" sur "OpenClassrooms".  
Ce site a pour objectif de présenter le portfolio professionnel de la photographe "Nathalie Mota" à travers une galerie dynamique et responsive.  

Le thème est basé sur "OceanWP" et développé en "thème enfant"  
Le code est versionné avec "Git" et le dépôt sera publié sur "GitHub" à la fin du projet.
